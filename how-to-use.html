How To Use

Step 1: Select a Creature

Use the search box to choose a dinosaur or creature from the list.

Step 2: Choose Colours

Each creature has multiple colour regions. Select a colour for each region to customise its appearance.

Step 3: Preview Changes

The preview updates automatically so you can see changes instantly.

Step 4: Generate Commands

Copy the generated admin command and paste it into your ARK server to apply the changes.

Extra Tools

Use Randomize for fully random colours or Smart Randomize for more natural-looking palettes.
