No account system, names, or contact details are collected. The only data the Website stores server-side is described in the next section.

10. Community Design Submissions

If you choose to use the “Share to Gallery” feature, the following is sent to our hosting provider (Cloudflare) and stored so the design can be reviewed and, if approved, shown in the public gallery:

• the selected creature and its colour region values
• the optional design name and credit name you type
• an irreversible one-way hash of your IP address, used only to limit submission spam (the raw IP address is not stored)

This feature is entirely optional. Do not enter your real name or any personal information in the optional fields if you do not want it shown. Approved designs, including any credit name, are publicly visible. To have a submission removed, contact the developer via the GitHub repository.

The “Advertise your server” form and the “Submit a palette” form work the same way: the details you enter (server name / banner URL / link, or the palette name and colours) plus any optional credit name are stored for review and, if approved, shown publicly, along with the same one-way hashed IP used only to limit spam.
